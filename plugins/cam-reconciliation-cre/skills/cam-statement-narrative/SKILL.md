# CAM Statement Narrative

Write concise tenant-facing commentary that matches the lease structure.

## Narrative Priorities

1. State the final FY charge and the true-up against pre-bills.
2. Name the lease feature that changed the charge.
3. Cite the clause section in plain English.
4. Keep the tone factual, not adversarial.

## Lease-Type Patterns

### Net

- Focus on the variance driver, usually realty tax.

### Modified gross

- Name the excluded categories and the dollar amounts removed.

### Base year

- Show the gross share, the base-year baseline, and the resulting payable over-base amount.

### CAM cap

- State whether the cap bound.
- If it did not bind, say that controllables remained below the ceiling.
- If it did bind, state the landlord-absorbed amount clearly.

## Constraints

- Do not mention internal implementation details.
- Do not imply that non-recoverable items were billed to the tenant.
- Do not omit the lease clause when an exclusion, base year, or cap is involved.
