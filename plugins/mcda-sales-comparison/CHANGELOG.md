# Changelog — MCDA Sales Comparison Plugin

## [1.0.0] — 2026-04-14

Initial release as a Claude Cowork plugin. Ported from `vp-real-estate` repository
(`MCDA_Sales_Comparison/` scripts + `.claude/commands/Valuation/mcda-sales-comparison.md`).

### Architecture changes from source

- **Subagent dispatch** — primary context handles only path resolution and argument parsing;
  a fresh 200k-token subagent runs validation, the calculator, verification, and report
  generation. Required by cowork_lessons_learned Lesson 1 (intermediate JSON pipeline).
- **Inline verification** — results JSON is verified against schema before report generation
  (Lesson 3: verify intermediate artifacts before downstream outputs).
- **cd to scripts dir** — calculator invoked as `cd <scripts_dir> && python3 mcda_sales_calculator.py`
  to resolve sibling imports (validation, score_to_price, weight_profiles).
- **SHARED_SCHEMA_PATH** — updated from `Shared_Utils/schemas/...` to a local `schemas/`
  path in the scripts directory (gracefully degrades when absent — no behaviour change).
- Removed `__init__.py`, `tests/`, `results/` from source — not needed in plugin.
- Markdown report generated by LLM from results JSON (no separate formatter script).

### Source files

- `mcda_sales_calculator.py` — unchanged from source v1.0.0
- `score_to_price.py` — unchanged from source v1.0.0
- `weight_profiles.py` — unchanged from source v1.0.0
- `validation.py` — SHARED_SCHEMA_PATH updated, otherwise unchanged from source v1.1.0
